\# FrameForge



\*\*AI-powered asset generation platform for content creators.\*\*



FrameForge helps users turn an idea or topic into the resources they need for content creation, including \*\*scripts, voiceovers, images, and animated images\*\*.



Instead of spending hours searching for assets and preparing resources manually, users can generate and organize the resources they need in one place and then use them in their preferred video editor.



> \*\*FrameForge generates content assets — it does not generate the final video.\*\*



\## ✨ Features



\* 📝 AI-generated scripts

\* 🎙️ AI-generated voiceovers

\* 🖼️ AI-generated images

\* 🎞️ Animated image generation

\* 📁 Asset organization

\* 📦 Exportable project resources

\* 👤 User accounts

\* 🔐 Authentication

\* 📊 Project dashboard

\* 🗂️ Chapter-based project organization



\## 🧠 How FrameForge Works



1\. The user creates a project.

2\. The user enters a topic or idea.

3\. FrameForge organizes the project into chapters.

4\. AI generates scripts and resource prompts.

5\. Voiceovers and visual assets are generated.

6\. The generated resources are organized for the user.

7\. The user downloads the assets and uses them in their preferred video editor.

\## 🚀 Getting Started



\### 1. Clone the repository



```bash

git clone https://github.com/salmanwkey-code/FrameForge.git

cd FrameForge

```



\### 2. Create a virtual environment



```bash

python -m venv venv

```



Activate it on Windows:



```powershell

venv\\Scripts\\activate

```



\### 3. Install dependencies



```bash

pip install -r requirements.txt

```



\### 4. Configure environment variables



Create a `.env` file and add the required API keys and Django configuration.



\*\*Never upload your `.env` file to GitHub.\*\*



\### 5. Apply migrations



```bash

python manage.py migrate

```



\### 6. Start the development server



```bash

python manage.py runserver

```



Then open:



```text

http://127.0.0.1:8000/

```



\## 🔐 Security



Sensitive information such as API keys, passwords, secret keys, and environment variables should never be committed to the repository.



FrameForge uses environment variables for sensitive configuration.
